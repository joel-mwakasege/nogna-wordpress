Native WordPress billing and financial management application based on Nogna.

== Development status ==

The plugin foundation is being built incrementally.

== Principles ==

* Custom frontend for normal billing operations.
* WordPress REST API as the application contract.
* Custom tables for financial data.
* Server-side calculations and permissions.
* Multiple company workspaces with strict isolation.
* No Supabase dependency for core functionality.
